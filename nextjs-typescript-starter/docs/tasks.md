# 单词学习平台 v1.2 精简任务清单

> 文档版本：v1.2（小项目精简版）
> 更新时间：2026-09-23
> 关联文档：[`proposal.md`](./proposal.md)、[`design.md`](./design.md)
> 涉及项目：`nextjs-typescript-starter`（H5）、`word-admin`（后台）
> 当前状态：模块 0–7 已完成

## 1. 执行原则

1. 一次完成一个模块，每个模块结束后都能看到页面效果。
2. 完成任务时把 `[ ]（状态：未完成）` 改为 `[x]（状态：已完成）`。
3. 数据库只新增迁移，不修改已经执行的迁移。
4. 不增加没有提出的审核流、监控平台、书籍版本或复杂架构。

## 2. 本期不做

- 不做草稿、发布和下架流程；管理员保存的单词书直接公开。
- 不做笔记本分享、协作、重命名、排序和批量管理。
- 不做中文搜索、拼写纠错、搜索引擎和大数据量优化。
- 不做多家发音供应商和通用音频平台。

## 3. 必要规则

- 普通用户使用 `app_users`，管理员使用 `admin_users`。
- 私人笔记本只对本人可见，不放进公共 `books` 表。
- 一个单词可以属于多本书，因此保留简单的 `book_words` 关联表。
- 删除书籍不能删除公共单词；`words.id` 对外统一使用字符串。
- 已经有人学习的书只允许在末尾增加单词，不删除和重排。
